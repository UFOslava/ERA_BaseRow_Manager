View Known Tokens Reference & Examples
Item Info:
- {{item_pn}}: Full Part Number (e.g. ERA-30-59-A)
- {{pn}}: Part Number without prefix (e.g. 30-59)
- {{revision}}: Revision letter (e.g. A)
- {{full_pn}}: Combined Part Number & Revision (e.g. 30-59 Rev.A)
- {{description}}: Description of the item
- {{ext_pn}}: External/Manufacturer Part Number
- {{date}}: Export date (YYYY-MM-DD)
- {{item_image}}: The main item image (if present)
Steps Loop & Index:
{% for step in steps %} ... {% endfor %}
- Use {{loop.index}} inside any loop to count iterations starting from 1 (e.g. 1, 2, 3...)
Step Info (inside loop):
- {{step.step_number}}: Step index (1, 2, 3...)
- {{step.main_action}}: Step's main action verb
- {{step.instruction_text}}: Full evaluated description
- {{step.step_image}}: Step's uploaded image (if present)
Parts & Tools Loops (inside step loop):
- {% for part in step.parts %} ... {% endfor %}
- {% for tool in step.tools %} ... {% endfor %}
Available properties on part and tool objects:
- {{part.pn}} / {{tool.pn}}: Part Number
- {{part.revision}} / {{tool.revision}}: Revision
- {{part.full_pn}} / {{tool.full_pn}}: Full Part Number (pn Rev.revision)
- {{part.description}} / {{tool.description}}: Description
- {{part.ext_pn}} / {{tool.ext_pn}}: External/Man. PN
- {{part.quantity}} / {{tool.quantity}}: Slot quantity
- {{part.image}} / {{tool.image}}: Image (if present)
Consolidated Flat BOM Loop (bom_items):
- {% for child in bom_items %} ... {% endfor %}
Available properties on child object:
- {{child.part_number}}: Full Part Number (pn Rev.revision)
- {{child.pn}}: Part Number
- {{child.revision}}: Revision
- {{child.description}}: Description
- {{child.ext_pn}}: External PN
- {{child.quantity}}: Consolidated required total in assembly
- {{child.image}}: Component image (if present)
Image Sizing (Pipe Filter):
Use | width:8cm filter on any image variable to change size, e.g.:
- {{step.step_image | width:8cm}} or {{part.image | width:3.5cm}}
Consolidated Unique Tools (unique_tools):
- {% for tool in unique_tools %} ... {% endfor %}
Available properties on tool object:
- {{tool.pn}}: Part Number
- {{tool.revision}}: Revision
- {{tool.full_pn}}: Full Part Number (pn Rev.revision)
- {{tool.description}}: Description
- {{tool.ext_pn}}: External/Man. PN
- {{tool.quantity}}: Consolidated required total used in assembly
- {{tool.image}}: Image (if present)
